# Data provenance and scope

The 10,000 English–French pairs are generated deterministically by `data/build_dataset.py`. Meaning groups are separated between training and evaluation. This is a constrained TF-IDF/classifier/retrieval pipeline; scores do not measure general-purpose neural translation.

This edition modernizes an earlier learning prototype with AI-assisted code and documentation. It is not an unchanged copy of the original implementation. The original source files remain preserved separately in the project archive.
